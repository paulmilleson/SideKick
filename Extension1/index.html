Sync Actual Google Drive

To connect the extension to your real live Google Cloud directory, run the updater script locally on your machine terminal using your signed-in Google account:

1. Authenticate with Google Drive

Open your powershell or command prompt and run this command to grant Google Drive permissions to your local Google Cloud CLI:

gcloud auth login --enable-gdrive-access
2. Navigate to Project Directory

In your terminal, navigate to the project directory:

cd c:\Users\owner\Documents\Extension1\Extension1
3. Run Updater Script

Execute the token builder script to write your live credentials to the local files:

powershell -ExecutionPolicy Bypass -File .\update-gcloud-token.ps1
4. Reload Extension

Go to chrome://extensions/ in Chrome, click Reload on SideKick, and open the Google Drive window to view real documents!
